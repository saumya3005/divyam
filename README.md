# Divyam

A full-stack SaaS platform built with Next.js, Express.js, TypeScript, and MongoDB.

## Tech Stack

### Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS

### Backend
- Node.js
- Express.js
- TypeScript
- MongoDB

## Features

- User Authentication
- JWT Authentication
- Role Based Access Control
- MongoDB Database Integration
- Scalable Frontend Architecture
- REST API Backend
